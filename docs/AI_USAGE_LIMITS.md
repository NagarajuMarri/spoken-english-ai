# AI Usage Limits

Usage records track provider kind, request counts, available input/output units, failures, retries, degradation, learner/account ownership, voice session, and period. Each provider dispatch also reserves a dated event before external work and reconciles its outcome, duration, and units afterward. The event's own `occurred_at` keeps daily and monthly attribution tied to the call time rather than the parent attempt's creation time; it stores no raw audio, transcript, or provider payload. Limits cover daily learner/account requests, voice-session requests, audio duration, transcript length, TTS characters, and provider retries. Billing and provider prices are intentionally excluded.
